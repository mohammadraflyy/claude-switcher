- **Switch & resume.** A new button in the dashboard switches accounts and opens a new window that continues your most recent conversation (`claude --resume`) on the new account. Whether an already-running session notices a plain switch is not verified, so the README and website no longer claim either way.
- **Usage alerts (opt-in).** Turn on *Usage alerts at 90% / 95%* in the tray menu. Claude Switcher then reads the 5-hour and 7-day usage that Claude Code passes to its statusline command, shows it per account in the dashboard, and sends a notification at 90% and 95% that names the saved account with the most headroom. It **never switches by itself**. Your existing statusline keeps running unchanged, turning the option off restores it (the original file byte for byte if nothing else changed it meanwhile), and the first version of `~/.claude/settings.json` is kept as `settings.json.switcher-bak`. If Claude Code sends no usage numbers for your plan or version, the dashboard says so instead of staying empty.
  - Numbers are only known for the account you are using and only while a session is open. The field depends on your plan and Claude Code version.
  - Switching accounts only to get around a usage limit may go against Anthropic's terms; that decision stays with you.
- Dashboard wording about running sessions is more careful.

The installer is not code-signed: if SmartScreen warns, choose More info, then Run anyway. Installing over an older version closes the running tray; open it again from the Start Menu.
