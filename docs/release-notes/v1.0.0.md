First release.

- Save several Claude Code logins and switch between them from the system tray, without logging in again.
- Local dashboard (click the tray icon): list, switch, remove, and save the current login.
- Saved logins are encrypted with Windows DPAPI. The current login is saved back before each switch so refreshed tokens are kept.
- Per-user installer, optional start with Windows.

The installer is not code-signed: if SmartScreen warns, choose More info, then Run anyway. Running `claude` sessions keep their account; open a new session after switching.
