- **Running-session warning.** The dashboard shows how many `claude` sessions are running and asks before switching, since they keep the account they started with. The tray notification says the same. Only the native `claude.exe` install is detected; npm installs are not.
- **Automatic token sync.** While the tray runs, the active account's saved copy is refreshed every 30 seconds when Claude Code rotates its tokens, so a switch never restores a stale login. A login caught half-written (during `claude /login` or a switch) is ignored.
- Saves, switches and removals are now serialized, so the tray, dashboard and sync thread cannot overwrite each other.

The installer is not code-signed: if SmartScreen warns, choose More info, then Run anyway.
