- **Unsaved login notice.** After `claude /login`, the tray tells you the new login is not saved yet, so you do not have to remember to press Save.
- **Update check.** The tray looks for a newer release every 6 hours (one anonymous request to the GitHub Releases API; nothing about you is sent). A newer version shows up in the tray menu and as a banner in the dashboard. Turn it off with **Check for updates automatically** in the tray menu.
- **npm installs are now counted** in the running-session warning, in addition to the native `claude.exe`.
- Repository history was cleaned of build output that had been committed by mistake; the release assets for v1.0.0 and v1.2.0 were rebuilt from the cleaned tags.

The installer is not code-signed: if SmartScreen warns, choose More info, then Run anyway. Installing over an older version closes the running tray; open it again from the Start Menu.
