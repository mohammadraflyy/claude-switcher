Windows 10/11 · tanpa hak admin

Semua yang dibutuhkan untuk berganti akun

Dibuat untuk yang punya akun pribadi dan akun kerja, atau lebih dari satu workspace.

Ganti sekali klik

Pilih akun di tray atau dashboard, atau tekan Ctrl+Alt+Shift+S untuk lompat ke akun berikutnya.

Login terenkripsi

Login tersimpan dienkripsi dengan Windows DPAPI. Hanya user Windows-mu yang bisa membukanya.

Sinkron token otomatis

Claude Code memutar token saat berjalan. Salinan tersimpan diperbarui tiap 30 detik, jadi ganti akun tidak pernah memulihkan login yang basi.

Peringatan sesi berjalan

Dashboard menghitung sesi claude yang masih terbuka dan bertanya dulu sebelum kamu ganti.

Label, warna, kedaluwarsa

Beri nama seperti “Kerja” atau “Pribadi”. Akun yang loginnya sudah kedaluwarsa ditandai dan dilewati.

Backup dan restore

Unduh akun tersimpan, tetap terenkripsi, lalu pulihkan nanti untuk user Windows yang sama.

Siap dipakai dalam beberapa menit

Kamu tetap login dengan cara biasa; Claude Switcher hanya mengingat setiap login.

  1. Unduh dan pasangJalankan installer; tanpa hak admin. Windows SmartScreen mungkin memperingatkan karena installer belum ditandatangani: pilih More info, lalu Run anyway.
  2. Simpan akun pertamaLogin dengan claude /login, lalu klik ikon tray dan tekan Save current login.
  3. Tambah akun lainJalankan claude /login dengan akun lainmu dan simpan juga.
  4. Ganti akunPilih akun. Sesi claude baru memakainya; sesi yang sudah berjalan tetap di akun lamanya.

Tetap di PC kamu

Claude Switcher menukar dua entri di file yang sudah dipakai Claude Code. Tidak ada yang diunggah.

  • Login dienkripsi dengan Windows DPAPI di %APPDATA%\ClaudeSwitcher.
  • Dashboard hanya mendengarkan di 127.0.0.1, tidak pernah mengirim token ke halaman, dan menolak permintaan dari situs lain.
  • Setiap penulisan atomik dan menyisakan .bak dari file sebelumnya.
  • Satu-satunya permintaan jaringan adalah cek update ke GitHub tiap 6 jam (anonim, bisa dimatikan di menu tray).
  • Open source berlisensi MIT, jadi kamu bisa membaca persis apa yang dilakukannya.

Perlu diketahui

Apakah boleh dipakai dengan akunku?

Hanya untuk akun milikmu sendiri. Memutar banyak akun untuk menghindari batas pemakaian, atau berbagi satu login dengan orang lain, melanggar ketentuan Anthropic dan bisa membuat akun diblokir. Ini alat tidak resmi dan tidak berafiliasi dengan Anthropic.

Kenapa sesi claude yang sedang berjalan tidak ikut ganti?

Sesi yang berjalan menyimpan loginnya di memori. Buka sesi baru setelah ganti akun; dashboard memberi tahu berapa sesi yang masih berjalan.

Bagaimana kalau update Claude Code mengubah cara menyimpan login?

Claude Switcher bergantung pada tempat Claude Code menyimpan login saat ini (~/.claude/.credentials.json dan ~/.claude.json). Update bisa mengubahnya. File aslimu dicadangkan sebagai .bak setiap kali ditulis.

Apakah jalan di macOS atau Linux?

Belum, saat ini hanya Windows.
